# Assets

| File | Use |
|---|---|
| `icon.png` | The logo (README, setup window) |
| `AppIcon.icns` | The Dock and app icon (built by `tools/make_icon.py`) |
| `menubar.png`, `menubar@2x.png` | The menu-bar template icon |
| `social-preview.png` | GitHub's preview image |
| `sounds/*.wav` | The 10 original sound cues (start, stop, lock, paste, cancel, alert, error, success, achievement, notification), generated by `tools/make_sounds.py`. Replace them with your own WAVs to change the sounds |
