# App switcher: tabs, browser commands, quit

**Branch:** `speaker-id`

Hold the switch key and say a command, alone (acts on the app in front) or with an app: "new tab in Chrome", or "Chrome new tab". With an app named, it's brought forward first and the shortcut is pressed 0.35 s later. Each command is the app's own shortcut, so it works anywhere that shortcut does.

| Say (and also) | Shortcut |
|---|---|
| new tab ("open a new tab", "open tab") | ⌘T |
| close tab ("close this tab") | ⌘W |
| reopen tab ("reopen closed tab", "undo close tab") | ⇧⌘T |
| next tab / previous tab | ⌃⇥ / ⌃⇧⇥ |
| tab 1 – tab 8 ("go to tab 3") / last tab | ⌘1–⌘8 / ⌘9 |
| new window / close window | ⌘N / ⇧⌘W |
| new private window ("incognito window") | ⇧⌘N |
| reload ("refresh") | ⌘R |
| back / forward ("go back") | ⌘[ / ⌘] |
| address bar ("url bar", "search bar") | ⌘L |
| find ("search", "find on page") | ⌘F |
| bookmark | ⌘D |
| zoom in / zoom out / actual size ("reset zoom") | ⌘= / ⌘- / ⌘0 |
| full screen | ⌃⌘F |
| quit Slack ("exit Slack") | asks the app to quit normally, so it can still warn about unsaved work |

Leading words like "go", "open" and "please" are ignored.
