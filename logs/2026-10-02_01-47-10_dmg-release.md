# DMG release build (v1.0.0)

**Asked for:** a downloadable DMG for GitHub, not Apple-signed, with no personal data ("just the app"), and its hash in the README.

## What was built
- `tools/build_dmg.sh` produces `dist/Mispr-Flow-1.0.0.dmg`: 87 MB compressed, the app is 241 MB.
- **SHA-256:** `ab4fe8b9008267b8a5f1ddd96851a225fc9e228ff98174085f01910786a85c51`.
- **Python:** a relocatable CPython 3.13.15 (python-build-standalone, via uv) with the pinned `requirements.txt`.
  - llama.cpp is compiled for macOS 14+ with Metal and with curl/OpenSSL off. The dev venv's build needed macOS 26 and linked Homebrew OpenSSL.
  - pip, the test suite, IDLE, tkinter and the library command-line launchers are removed.
- **Engine:** `mispr/` only, git-tracked files only. Bytecode is precompiled, so nothing is written into the app.
- **App:** `MisprBundled` in Info.plist replaces the checkout paths. `EngineConfig.resolve(resources:)` then runs `Resources/python/bin/python3` on `Resources/engine`.
- **Data:** `storage._data_root()` uses `~/Library/Application Support/Mispr_Flow` when the engine is inside an .app. The app creates its folders on first run.
- **Signing:** ad-hoc, inside out (`codesign --verify --deep --strict` passes). There is no Developer ID, so the first open needs right-click → Open, as the README explains.
- **Version:** 1.0.0.

## Privacy checks (the build fails if any trips)
- Every engine file must be tracked in git.
- None of these may be in the app:
  - audio (other than the app's own sound effects);
  - models (`.gguf`, `ggml-*.bin`, `.onnx`);
  - `settings.json`, `people.json`, prompts or profile JSON;
  - recordings folders, `engine.log`, `.env`.
- No text or binary file may contain `$HOME/`, `<user>@`, or the owner's email.
- Every Mach-O must link only inside the app or the system, and require at most macOS 14.

**Leaks found on the first runs, and fixed:**
- pip's bytecode and the launchers' first lines held the build folder: bytecode recompiled with relative paths, launchers deleted.
- uv had written its install folder into `_sysconfigdata` and libpython's install name: replaced with `/install` and `@rpath`.
- The Swift binary's debug symbols named the checkout: stripped.

## Verified
- The DMG was mounted read-only.
- The bundled Python imports llama_cpp 0.3.35, pywhispercpp, sherpa_onnx, numpy, soxr, AppKit, Quartz and the engine.
- The recordings folder resolves to Application Support.
- The signature verifies.
