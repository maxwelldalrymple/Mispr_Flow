# The tour starts right after setup

**Branch:** `tour-after-setup`

**Report:** "The tutorial doesn't start when you finish the setup. It should start immediately after."

**Cause:** the tour only checked when the main window first appeared. Setup runs in the engine (another process), and finishing it never told the app.

**Fix:**
- **Engine:** the setup window's `on_finish` (called after `onboarded` is saved) runs `widget.on_setup_finished`, which `_connect_host` wires to send a new event, `setup_finished`.
- **App:** `EngineEvent.setupFinished` → `Engine.setupFinished` → `AppModel.setupFinished()`, which shows the main window (`showMain`, set by AppDelegate) and calls `startTourIfNew()`. The tour starts the first time only; reopening setup later from the menu doesn't replay it.
