# UI screenshots

**Asked for:**
- screenshots of every window of the app, including every tour stage;
- Incognito on and Auto-Enter on;
- every theme in light and dark;
- descriptive file names.

**What was made:** `tools/screenshots.sh` writes 146 PNGs (30 MB) into `docs/screenshots/`, with an index README.

| Folder | Shots | What |
|---|---|---|
| main-window/ | 36 | 18 states × light/dark: every page, the commands history, more insights, people, a selected person, shared meetings, the 4 meeting-detail tabs, the contact editor, Incognito on, Auto-Enter on, and both on |
| settings/ | 8 | 4 sections × light/dark |
| tutorial/ | 16 | 8 tour steps × light/dark |
| themes/ | 36 | 6 themes × light/dark × Home, Notetaker, Insights |
| note-window/ | 20 | 10 states × light/dark: permission, ready, recording, each tab, answered question, save card, save question, saved with summary |
| setup-window/ | 9 | the Python setup goldens, renamed |
| floating-widget/ | 21 | the Python widget goldens, renamed |

**Naming:** `<window>_<page>_<state>_<theme>-<light|dark>.png`.

**How:**
- `macos/Tests/MisprFlowTests/ScreenshotTests.swift` renders each view offscreen at 2× with the existing `render` helper. The helper has a new `appearance:` parameter (light or dark), and its other callers are unchanged.
- The sample data is made up (user "Alex Rivera", fictional meetings and contacts). No real recordings, notes or settings are read, and no Screen Recording permission is needed.
- The test is skipped unless `MISPR_SCREENSHOTS` is set, so the normal `swift test` doesn't write files.

**Tests run:** `swift test --filter ScreenshotTests` (via the script): 6 passed. Each screenshot is also checked to be non-blank. Shots were checked by eye, including the tour step 3 outline, the Incognito and Auto-Enter top bar, Sunset light and Ocean dark, and the live note transcript.
