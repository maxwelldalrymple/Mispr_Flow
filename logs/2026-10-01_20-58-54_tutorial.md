# First-run tutorial

**Branch:** `tutorial`

**Request:** a tour of the start and every page, about 8 steps. It outlines each area with a tooltip, and you can press Next, skip a step, or skip everything.

## What it does

- On the first main-window open **after setup is finished** (`onboarded`), an 8-step tour runs.
- Each step switches to its page, dims everything else, outlines one spot in the accent colour, and shows a card with "N of 8", a title, one or two sentences, and **Skip tour / Back / Next** (Done on the last step).
- Next moves past any step. Skip tour ends it at once.
- **Finishing or skipping** sets `profile.tutorialDone` (UserDefaults). It won't start by itself again; replay it from **Help → Show Tutorial** (a new Help menu) or Settings → System → Tutorial.

| # | Page | Outlines |
|---|---|---|
| 1 | Home | the dictation key in the greeting |
| 2 | Home | history (Dictation / Commands) |
| 3 | Home | Auto-Enter + Incognito |
| 4 | Home | Voice commands card |
| 5 | Insights | the page |
| 6 | Notetaker | New note (⌥M) |
| 7 | Prompts | the page |
| 8 | Sidebar | Settings |

## How it works

- `Views/Tutorial.swift`:
  - views mark themselves with `.tourSpot(_:)`, which records their bounds in an anchor preference;
  - `RootView` reads them with `overlayPreferenceValue` and draws `TourOverlay`: an even-odd dimming path with a hole, an outline, and the card;
  - card placement: below the spot, else above, else beside, else centred.
- **Bug found by rendering:** the page container's own spot used `anchorPreference`, which *replaced* the spots inside it, so the fn key, history and commands weren't outlined. Fixed with `transformAnchorPreference`, which merges. Steps 1, 3, 4 and 6 were checked visually as rendered images.
