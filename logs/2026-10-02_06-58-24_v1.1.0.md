# v1.1.0: auto-update, Auto-Enter key, dictation and voice command fixes

## Bugs reported by the owner, and causes (from their own recordings)

| Report | Cause | Fix |
|---|---|---|
| "close tab" doesn't work | Whisper wrote "Closed tab." and "Tab, close." | `fix_misheard` maps both to close tab, but leaves "reopen closed tab" alone |
| Clicks make phantom text | Clicks and silence came out as "Thank you.", ".", "Captions by GetTranscribed.com", "*Drums*". Speech measured 0.00 s in every one | The Silero speech check runs before Whisper, on a copy at an even volume that is wiped afterwards. On the owner's recordings, all real words measured ≥ 0.20 s and every phantom 0.00 s, so the cutoff is 0.1 s. Credit lines, punctuation-only output and `*labels*` are removed too |
| Ums and uhs left in | "Uhh... YouTube?": the guard didn't count "uhh" as a filler, so it rejected the cleanup | Filler sounds matched by pattern in the guard, plus `strip_fillers` after cleanup |
| "GitHub tab" always "no tab" | AppleScript `tab` inside a Chrome tell block means a browser tab, not ⇥ | The separator is set outside the tell block. Checked live: 9 Chrome tabs read |
| "chat GBT", "get up" misheard | — | Whisper is primed with site names; name fix-ups; the top 1,000 sites for tab commands and spoken addresses |

## New features

- **Long dictations in pieces** (> 20 s): cut at pauses (`split_points`), each piece typed in as it's ready. Pastes are queued so the clipboard is never lent out twice. Auto-Enter fires once, at the end.
- **A tab by its site**: "GitHub tab", "YouTube tab 2", "Chrome tab 3". Misheard names are assumed; a site that isn't open gets opened.
- **System commands:** screenshot (⌘⇧3 / ⌘⇧4), screen recording (`screencapture -v`, falling back to the ⌘⇧5 toolbar), sleep (`pmset sleepnow`), lock (⌃⌘Q). Log out, restart and shut down go through loginwindow's own confirmation dialogs.
- **Menu items by name** (AX menu bar, 0.26 s for Finder). Items that delete for good are blocked.
- **Auto-Enter key** ⌃⌥↩ (`auto_enter_hotkey`, changeable in Settings). Auto-Enter presses **⌘Return** on LinkedIn, Gmail and Outlook web.
- **Automatic updates** (`Updater.swift`, `Update.swift`):
  - GitHub's latest release, about 5×/day;
  - the DMG plus its `.sig` (Ed25519 over SHA-256, key in `~/.config/mispr-flow/`, public key in the app);
  - the version and bundle ID are checked, then the new app is staged and installed after 60 s idle (engine `busy` event, meetings);
  - a helper swaps the copies and relaunches;
  - the Settings switch and Check now.
- **Release signing:** the "Mispr Flow Local Signing" certificate on every release, so permissions survive updates.

## Tests

- **Full Python suite:** passes. New tests:
  - phantoms, speech gate, split points, chunked transcription;
  - fillers, close-tab mishearings, site tabs and popular sites, names and echoes;
  - system and menu commands, the screen recorder;
  - the Auto-Enter key, the send key, long dictations in pieces, the speech check.

- **Bugs the tests caught:**
  - the prompt-echo check matched "one" inside "iPhone", so it would have dropped a dictated "One.". It now compares whole words.
  - a widget test reached the real "open site" call; it's stubbed now.
