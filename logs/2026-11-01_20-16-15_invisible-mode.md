# Invisible mode

**Asked for:** a key combo "like ctrl + i" that makes the pill at the bottom invisible and impossible to interact with, while everything else works the same.

**Key choice:** **⌃⌥I** by default, changeable in Settings. Plain ⌃I is Tab in Terminal, so taking it would break Tab-completion.

**What changed:**
- **`settings.invisible` and `invisible_hotkey`** (default ⌃⌥I).
- **Widget:** `apply_invisible` sets the panel's alpha to 0 and makes it ignore the mouse, so notices hide too. Recording, pasting, commands and sounds are untouched.
- **Key watcher:** `set_extra_toggle` adds any number of on/off keys next to Auto-Enter's. Each one is swallowed, so the app in front never sees it.
- **Voice:** "invisible mode" (on/off, or flip).
- **App:** Settings → General has the **Invisible widget** switch and an **Invisible mode key** recorder. The Voice Commands page lists the phrase.
- **Bug found by the new test:** `reload_settings` compared the reloaded invisible value with itself, so the mode-change chime could be skipped. It now keeps the old value, as Auto-Enter does.

**Tests run (affected files only):**
- **Python:** `test_hotkey`, `test_widget`, `test_control`, `test_command_catalog`, `test_settings_models_setup`, `test_entrypoints`, `test_host`, all passing. New tests cover:
  - each on/off key calling its own handler;
  - ⌃I and I still typing normally;
  - turning the key off;
  - the panel hidden and click-through;
  - dictation still pasting while invisible;
  - the key and voice flipping it, with the chime;
  - "Widget visible again".
- **Swift:** `UpdateTests`, `AutoEnterKeyPickerTests`, `SmokeTests` pass; the app builds.
