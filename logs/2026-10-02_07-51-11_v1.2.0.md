# v1.2.0: control your whole Mac by voice

## Asked for
- Click anything on screen by voice, in browsers first, then "every single app": no OCR if the app can say what's there.
- The closest name wins when nothing matches exactly ("opus", "pref five", "thru").
- Everything from the gap list: keyboard, editing, windows and desktops, switches, the web, the mouse grid and drag, Shortcuts, repeat, custom commands.
- Modes by voice (Auto-Enter, Incognito).
- A Voice Commands page that looks great and is accurate.
- Stable and beta updates: betas offered, never automatic, and never shown once a newer stable release exists.
- Live long dictations as a switch, off by default.
- **Bugs:** "YouTube tab" not working in a text box; hearing things not said; screen recording.

## Findings
- **"YouTube tab" / "close tab" / "new tab" dropped (1.1.0–1.1.1):** the prompt-echo check matched any 2+ word phrase found in Whisper's command hint. The log showed "switch heard 0 chars" for each attempt. The text box had nothing to do with it. Echoes now need half the prompt.
- **Screen recording:** the owner will reset permissions and retest.
- **Hearing things not said:** needs examples; the saved recordings will show it.

## How
- **`pointer.py`:** the Accessibility tree of the front window plus the menu bar, a breadth-first scan capped at 6,000 elements / 2 s.
  - Chrome reports web content after `AXManualAccessibility` / `AXEnhancedUserInterface`. Measured on the owner's Chrome: 127 targets in 0.14 s, including page links. Finder: 0.08 s.
  - Matching order: exact, prefix, words, field words, then closeness (a word-by-word best match with prefix, spelling, Soundex and exact numbers, plus whole-phrase similarity); minimum 0.6, ties within 0.05 become numbers.
  - Text inside a link merges into the link.
- **`overlay.py`:** a click-through window at screen-saver level; badges on targets; the grid draws cell outlines with centered numbers.
- **`control.py`:** parsing for keys, typing, editing, snapping, desktops, Mission Control, dark mode, Wi-Fi, brightness, CoreAudio output, searches, go-to, find, Spotlight, Shortcuts, again, grid, drag, scroll-in and custom commands.
  - It runs before the older parser on unconverted words ("left half" isn't "left 50"). Corners need "corner" or "move to", because "top left" is Whisper's "tab left".
- **Updates:** `Update.choose` reads `/releases` (stable vs prerelease); `isNewer` orders betas; Settings has Install beta; `tools/release.sh` publishes either.
