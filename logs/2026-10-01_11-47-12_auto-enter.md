# Auto-Enter button

**Date:** 2026-10-01 11:47 · **Branch:** `speaker-id`

A ⏎ button in the window's top bar, left of Incognito. Clicking it turns Auto-Enter on or off (setting `auto_enter`, off by default). When it's on, the engine presses Return 0.25 s after dictated text lands in a text box, so chat messages send themselves. The delay lets the app take the paste before Return arrives. It never presses Return when there was no text box and the text was copied instead. Hovering shows an explanation card; Incognito's hover card now uses the same `InfoCard` view.
